🔒 BlindBid — Sealed-Bid Auction Agent

A sealed-bid first-price auction agent for Agent Games (zkVerify), Wildcard track. Bidders commit to a hidden bid with a Groth16 proof that it is in range — the agent never sees a bid before the reveal, then settles the winner.

How it works

  1. Create — the agent signs the auction config (item, min/max bid, close time) into a ticket.
  2. Bid — a bidder sends a commitment = Poseidon(bid, salt) plus a Groth16 proof that the hidden bid is inside [minBid, maxBid]. The agent verifies the proof and returns a signed bid receipt. The bid itself never leaves the bidder.
  3. Reveal — after the close time, each bidder reveals (bid, salt) with their receipt. The agent recomputes the commitment and requires an exact match.
  4. Settle — the agent re-verifies every reveal, rejects duplicate bidders, and signs the winner: the highest revealed bid.

The agent is stateless: every step is carried by a signed receipt, so it runs on serverless (Vercel) with no database. One bid per bidder is enforced at settlement, where all reveals are visible. The demo bids below are public by design so anyone can run the demo — a real bidder generates their own proof with scripts/prove.js and keeps bid + salt secret until the reveal.
